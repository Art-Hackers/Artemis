Artemis

A stupidly easy way to build Android and desktop apps in Python.
› Python 3.8+ › pip install artemis-ui › v0.1.0

› Quick Start

import artemis as art

app = art.App("Hello", theme="ocean")

@app.page("/")
def home(page):
    return art.Column([
        art.Title("Hello, Artemis!"),
        art.Button("Say hi", on_click=lambda e: print("hi!")),
    ], center=True)

app.run()

Run it locally, then build for Android or desktop with Flet tooling underneath.

› Mental Model

Artemis is intentionally small. The core concepts are:

One App per application
@app.page("/route") for pages
art.State(...) for state management
Auto-redraw on state changes
Navigation with app.go()
Built-in themes (ocean, sunset, etc.)

› Available Widgets

Common UI building blocks, all wrapped for a Pythonic feel:

  • Text, Title, Button, Input, Switch, Checkbox, Slider, Dropdown
  • Column, Row, Box, Card, Spacer, Divider, Image
  • BottomNav, ListTile, Avatar, Loader, ProgressBar
  • App, State, toast(), alert(), and confirm()

If a control is not yet wrapped, you can still use Flet directly with import flet or art.flet.

› Examples

Reference apps in the repository:

  • examples/counter.py — Simple state handling
  • examples/todo.py — Dynamic lists and input binding
  • examples/showcase.py — Navigation, glass panels, gradients
  • examples/contacts.py — Lists, avatars, loaders, and dialogs

› Build for Android & Desktop

Once your app is ready, use Flet's build commands:

flet build apk      # Android
flet build ipa       # iOS
flet build macos     # macOS
flet build windows   # Windows
flet build linux     # Linux

› Current Limitations

  • Page redraws happen on state-driven updates (simple and effective, but not ideal for very large datasets)
  • Routes are currently flat strings (e.g., / and /settings)
  • Bottom navigation is designed for a single tab level
  • Widget coverage is intentionally narrow and will grow over time
