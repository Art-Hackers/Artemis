app.py
import artemis as art

app = art.App("Hello", theme="ocean")

@app.page("/")
def home(page):
    return art.Column([
        art.Title("Hello, Artemis"),
        art.Button("Say hi", on_click=lambda e: print("hi!")),
    ], center=True)

app.run()
Features

Why Artemis?

Everything you need to build Python apps, beautifully simple

1

Pages as Functions

Decorate with @app.page("/route"). Each page returns a UI tree.

2

State-Driven Updates

Use art.State(...) and UI redraws automatically. No manual update().

3

Navigation & Tabs

app.go("/details") with back handling & app.bottom_nav([...]).

4

Built-in Themes

indigo, ocean, forest, sunset, grape, and more.

5

Android & Desktop

Build for Android, Windows, macOS, Linux with Flet tooling underneath.

6

Flet Compatible

Use raw Flet controls when needed. Artemis widgets return standard Flet controls.

Value Add

What Artemis adds on top of Flet

app.toast("Saved!")Snackbar feedback in one line
art.Box(glass=True)Glass effect without manual Flet effects
art.Box(gradient=[...])Visual patterns without constructing Flet effects
app.bottom_nav(...)Persistent tab bar for root-level navigation
app.go("/details")Real navigation view with back handling
art.State(...)Clean state management with auto-redraw

Assets

Branding & Assets

First run adds logo.png, icon.png, and logo.ico to assets/.

Override with App(..., logo="brand.png") or app.run(assets_dir="static").

If Pillow is installed, Artemis generates an .ico from your custom PNG.

Current Limitations

  • Flat routes (strings like / and /settings)
  • Single tab level for bottom navigation
  • State-driven redraws — simple and effective but not for huge datasets
  • Widget coverage grows over time
