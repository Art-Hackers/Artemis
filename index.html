import artemis as art

app = art.App("Hello", theme="ocean")
@app.page("/") def home(p): return art.Column([art.Title("Hello"), art.Button("Say hi", on_click=lambda e: app.toast("Hi!"))], center=True)
app.run()

What Artemis gives you

Theming

31 named color palettes, automatic light/dark, and manual color control — Material 3 correct.

Navigation

Real back-stack semantics, bottom tabs, route guards, and params — behaves like a native app.

State & Forms

Persistent and async state, fields with validation, and simple forms with one-line submit.

Testing

TestApp tooling to run clicks, navigation, dialogs, and assertions without opening windows.
